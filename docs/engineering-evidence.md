以下只统计 TypeScript CLI 的实现与验证。参考项目和旧产品的测试不计为新版成果。

## 复现

在仓库根目录运行：

```powershell
npm.cmd run check
npm.cmd run eval -- --repeat 2
npm.cmd run smoke:pack
```

测试使用真实文件与 Pi SDK 的可控 Provider。Eval 默认固定正确性案例，不调用真实模型，也不代表文学质量。
当前验证结果：145 项测试、类型检查与构建通过；两次重复确定性评测均通过；安装包在源码目录外启动并完成独立评测。新书无需预填标题，未命名草稿先保存，确定书名后整理到 `books/<书名>/`。覆盖候选/自填/返回、草稿及启动意图恢复、命名移动、同名不覆盖与并发锁保护。
TUI 按阶段显示共创双栏/写作三栏；单页模型设置覆盖编辑不落盘、明确保存、遮罩及在途 IO 取消。F2 菜单按阶段过滤并搜索。结构化事件按任务组织，同一工具调用更新状态和实测耗时。真实 Windows 180×48 终端已验证共创页、F2 中文搜索、单页设置、原位编辑 128K、取消和退出。
真实模型评测用 `npm.cmd run eval -- --real`，需要先配置模型。每次输出到新建隔离目录，报告路径由命令打印。

2026-09-14 在 Windows / Node.js 24.12.0 已做实际终端操作：中文多行输入、模型未配置提示、设置弹窗取消、诊断、退出。
复制/缩放/快捷键和凭证不泄露另由真实 pi-tui 组件配合 FakeTerminal 测试覆盖。

## 当前证据限制

- 尚未配置真实模型凭证，没有真实 Provider 鉴权、中文长篇效果、文学质量或成本优化成绩。
- Pi 压缩测试证明保护上下文的调用路径，不证明模型摘要永远保留全部小说事实。
- 仅在 Windows 实测；其他操作系统与更多终端仍需实际验证。
- 部分人工同步已接纳后，又修改尚未接纳章节时，会保留恢复证据并报冲突，不进行未设计的自动修复。
- 时间上限使用协作式取消；若 Provider/Runner 不响应取消，会继续等待在途操作停稳，不能提前释放书目录。
- 未运行外部 EPUBCheck；现有检查覆盖 EPUB 必需条目、ZIP 偏移、导航与 XML 转义。
- 费用未知时保持 null；可用 token 计数不包含 SDK 独立压缩请求等未报告到任务消息流的消耗。

这些限制不应被写成已测的面试指标。先用真实模型完成可复现案例，再补充语义质量与成本数据。

# 新版工程证据

只记录 `cli/` 实际实现和验证结果；旧产品及参考项目的测试、指标不计为新版成果。

## 当前已验证

2026-09-14，Windows，Node.js 24.12.0：

- Pi SDK 角色会话使用明确工具白名单、串行工具执行，保留 SDK 的下一回合刷新机制。
- 当前任务产物匹配、缺产物有限纠偏、跨重派共享回合预算、模型错误与取消分流。
- 取消等待协作工具收尾；已经确认保存的产物不被随后取消改写成未完成。
- 多轮讨论保留历史，新任务会话隔离；切换模型不改写在途响应的模型标记。
- 操作系统目录锁阻止跨进程重复占用，持锁进程强制结束后可再次获取。
- 单文件写入及串行修改队列；退出等待任务与事件消费者后再释放锁。
- 安装包在源码树外启动，书目录与资源目录正确；真实终端接受中文输入并退出恢复。

复现：根目录 `npm.cmd run check` 和 `npm.cmd run smoke:pack`。当前确定性测试共 13 项，均不产生真实模型费用。

## 证据边界

文件写入基础不代表跨文件提交恢复已经完成；内存产物夹具不代表真实章节接纳协议。
TUI 入口不代表完整创作体验。真实模型语义效果、其他操作系统、完整滚动/缩放交互仍待验证。
尚未实现完整 Host 调度、章节恢复、用户意见、Skills、导出、诊断与评测产品流程，不能作为已交付简历成果。

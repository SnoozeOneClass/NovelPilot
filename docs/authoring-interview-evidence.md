# Authoring Harness Interview Evidence

The project demonstrates a long-running Agent harness through one beginner-facing product path:
idea, automatic planning, chapter writing, quality review, bounded revision, completion, and export.

Evidence that can be claimed from deterministic tests:

- Pure routing returns a stable instruction identity for the same persisted facts.
- SQLite commits domain facts, checkpoints, tool evidence, Canon updates, and events atomically.
- Replayed tools do not duplicate chapter side effects.
- One active lease prevents two engines from writing the same project; the Web start handshake
  distinguishes this process from a different process holding the lease.
- A real Pydantic AI tool loop reaches the persisted Tool Gateway, compacts an intentionally small
  context, restores mandatory facts, and commits the authorized chapter.
- Fallback is allowed only before emitted output and tool side effects; the actual Profile and cost
  snapshot are recorded.
- Each Provider request records its Episode, chronological request index, purpose, success/failure,
  cache usage, price-derived cost and any Engine-applied retry delay.
- TXT/Markdown rendering, digest, immutable content blob and export manifest commit atomically.
- Web pause and cancel wake the active request while persisted SQLite status remains authoritative.
- SSE replays the database event sequence with `Last-Event-ID`; the browser keeps no second progress
  truth.
- Eval reports source, prompt, case, Profile, request-option and price fingerprints.

Fake runs prove workflow contracts, not prose quality or real-provider reliability. A paid run may
be cited only after an explicitly authorized real Eval completes and its report is retained.

The 2026-09-09 validation first exposed a usage dependency mismatch, physical-request budget
mismatch and retry/resume gaps. After the approved repairs, the real three-chapter case completed
with PASS, three committed chapters and no deterministic diagnostic findings. The retained report
is `output/validation/runtime-20260909-2b4ca407/report.json`, with its manuscript beside it.

This one run contains 36 model requests, 353,545 input and 36,749 output tokens. Two failed
postamble Episodes remain visible: Foundation work was recovered from its durable terminal facts,
and a write attempted after book completion was rejected. Model-request/Episode outcomes must not
be conflated with final project status. This is one completed real case, not a statistical
long-book reliability claim. Configured prices are unspecified/zero; the cost field cannot be
cited as evidence of free generation. Duplicate body/export chapter headings remain a recorded
formatting follow-up.
